# kirakira-eye

白い球が銀河のように幻想的な渦巻き運動を描く、シンプルなWebGLシーンです。

## デモ

[プロジェクトのGitHubページ](https://js.sabae.cc/kirakira-eye/)でデモをご覧いただけます。

## 特徴

- 複数の球が連続的に渦を巻くように軌道運動する様子を表示します。
- URLパラメータを使用して、球の数（デフォルト: 8）とサイズ（デフォルト: 0.5）をカスタマイズ可能です。
- 依存関係はありません。WebGLをサポートするモダンなWebブラウザであれば動作します。

## 使い方

ローカルで実行するには、Webブラウザで `index.html` ファイルを開くだけです。

URLの末尾に `#<count>,<size>` の形式でハッシュを追加することで、球の数とサイズをカスタマイズできます。

例えば、サイズ0.3の球を20個表示するには、以下のURLを使用します。

[`https://js.sabae.cc/kirakira-eye/#20,0.3`](https://js.sabae.cc/kirakira-eye/#20,0.3)
