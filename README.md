# kirakira-eye

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple WebGL scene featuring white spheres that swirl in a mesmerizing, galaxy-like motion.

## Demo

View the demo at the [project's GitHub page](https://js.sabae.cc/kirakira-eye/).

## Features

- Displays a cluster of spheres in a continuous, swirling orbital motion.
- Customize the number of spheres (default: 8) and their size (default: 0.5) via URL parameters.
- No dependencies; runs in any modern web browser with WebGL support.

## Usage

To run the project locally, simply open the `index.html` file in a web browser.

You can customize the number of spheres and their size by appending a hash to the URL with the format `#<count>,<size>`.

For example, to display 20 spheres with a size of 0.3, use the following URL:

[`https://js.sabae.cc/kirakira-eye/#20,0.3`](https://js.sabae.cc/kirakira-eye/#20,0.3)
